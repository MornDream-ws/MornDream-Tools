# 图片工具工作区实施清单

## 目标与范围

在 MornDream-Tools 中独立实现 19 项图片工具，参考 Aimg 的功能，不复制其代码、品牌或页面素材。保持静态部署、简体中文、电脑与手机可用。本轮完成图片区内部操作，现有工具、API 调试台、CyberChef、SDK/MCP 联动在后续单独实施。

完成状态以实现和验收证据为准：只有对应检查通过才勾选；代码存在但尚未验证的项目保持未勾选。

## A. 依赖与许可证

- [x] A01 核实直接依赖的版本、许可证及来源，保存许可证原文与必要的第三方声明。
- [x] A02 分别记录抠图和人脸检测模型来源、固定版本、许可证及下载地址。
- [x] A03 静态构建包含许可证和模型来源说明，主项目继续使用 GPL-3.0-only。

## B. 共用工作台

- [ ] B01 顶部图片工具入口；五组分类、19 个工具、区内搜索。
- [ ] B02 支持多文件选择、拖放、粘贴图片；非法或不支持的文件显示明确错误。
- [ ] B03 文件缩略图、选择、移除、全选、排序及原图基本信息。
- [ ] B04 原图与结果切换、缩放、透明背景；显示结果格式、宽高、体积。
- [ ] B05 参数面板、恢复参数、恢复原图结果；参数变更标记需要重新执行。
- [ ] B06 当前图片或所选图片执行；逐个处理、进度、错误定位及取消，失败不丢失其他结果。
- [ ] B07 单项下载、批量 ZIP、清晰的文件名；释放移除图片和旧结果的 URL。
- [ ] B08 输入和结果仅保留内存，不进入历史、收藏、工作区备份。
- [ ] B09 手机布局和键盘可访问控件；处理中的界面保持可操作。

## C. 19 项工具

每项均需：有效输入、参数生效、可预览、可导出或复制、错误提示。批量能力以工具页标注为准；GIF/PDF 是合成任务，交互编辑以当前图片为准。

- [x] I01 图片压缩：JPG/WebP 质量、最大边尺寸、PNG 输出；显示前后大小，不保证每次变小；动画输入需明确处理方式。
- [x] I02 图片放大：2×/3×/4×，可调锐化；明确为重采样与锐化，尺寸过大时明确报错，不静默缩小。
- [x] I03 背景移除：真实本地模型、下载进度、取消；透明 PNG 或指定背景色；加载失败可重试，不替换成伪抠图。
- [x] I04 修改尺寸：宽高、百分比、比例锁定、有效尺寸校验。
- [x] I05 图片裁剪：拖动框选、比例预设、精确坐标与尺寸；限制在原图内。
- [x] I06 旋转与翻转：任意角度、水平/垂直翻转，扩展画布避免截断。
- [x] I07 照片编辑：亮度、对比度、饱和度、色温、滤镜、文字、边框，实时参数预览与原图对照。
- [x] I08 转为 JPG：质量、透明区域背景色，输出实际 JPEG。
- [x] I09 JPG 转其他格式：PNG、WebP、GIF；输出格式、扩展名与文件内容一致。
- [x] I10 图片转 PDF：顺序、A4/Letter/图片尺寸、横竖方向、页边距；每图一页、可打开。
- [x] I11 HTML 转图片：HTML/CSS 输入、宽高、倍率、PNG/JPG；隔离渲染，禁用脚本、表单、远程资源，不自动发起外部请求。
- [x] I12 表情包：上下字幕、字号、颜色、描边，位置可调。
- [x] I13 GIF 制作：多图排序、逐帧时长、循环次数、统一尺寸；导出含多帧动画。
- [x] I14 调色板与取色：主色数量、点击取色、HEX/RGB/HSL、颜色列表导出。
- [x] I15 清除 EXIF：查看解析元数据；JPEG/PNG/WebP 按文件结构移除元数据并保持像素压缩数据不变，其他格式明确提示。
- [x] I16 人脸模糊：真实本地自动检测、手动添加/删除区域、模糊或马赛克、强度调节。
- [x] I17 图片水印：文字/本地 Logo、位置、大小、透明度、平铺。
- [x] I18 网站图标：含 16/32/48 ICO、180/192/512 PNG、manifest、HTML 引用代码的 ZIP，文件可解析。
- [x] I19 图片转 Base64：Data URI、HTML、CSS、Markdown；复制和文本下载，保留原始文件字节。

## D. 数据与执行约定

- [ ] D01 原始 Blob 始终保留，切换工具默认从原图处理，不暗中串联已有结果。
- [ ] D02 GIF 动画输入明确标记，静态工具提取首帧前需用户勾选；GIF 制作使用图片帧合成。
- [ ] D03 透明度、EXIF 方向、浏览器格式解码差异有对应处理与提示。
- [ ] D04 较重算法使用可终止 Worker；批量串行处理，检查画布尺寸与内存预算。
- [ ] D05 AI 功能按需加载，显示模型来源和下载情况，图片不上传，取消后不回写过期结果。
