# 图片工具工作区

点击顶部“图片工具”，在左侧分类或搜索中选择工具。图片仅保留在当前页面内存中，刷新后清空，不写入工作区备份。处理使用原始图片；切换工具不会自动把上一步结果作为输入。

## 添加与处理

- 点击“添加图片”，或把文件拖到页面；在非文本输入区域粘贴剪贴板图片。
- 文件栏支持选择、移除和前后排序。GIF/PDF 按选中图片的顺序合成。
- 参数区选择处理当前图片或所选图片。裁剪、编辑、取色、人脸区域、水印 Logo 等按工具页提供的控件操作。
- 点击“开始处理”或使用 Ctrl/⌘ + Enter。处理期间可取消；参数改变后需要重新处理才能下载。
- 在原图与结果之间切换预览、调整缩放。下载单项结果，或下载所选已处理结果的 ZIP。
- “恢复参数”还原工具默认值；“恢复原图”清除当前图片结果。原始文件始终保留。

## 格式与资源

图片放大使用重采样和锐化。压缩结果会显示体积变化，PNG 或已压缩的输入可能变大。动画输入用于静态处理时，需要确认提取首帧；制作 GIF 使用文件栏中的图片合成帧。

无损清理支持 JPEG、PNG、WebP，保留像素压缩数据。若 JPEG 包含非默认 EXIF 方向，为保持画面方向会转换为 PNG，并在结果中说明。Base64 保留原始文件字节。

单张输入最多 100 MiB；画布每边最多 16,000 像素、总计最多 3,200 万像素。合成任务解码图片总计最多 6,400 万像素。超过限制时先缩小图片或减少合成数量。

HTML 转图片隔离渲染 HTML/CSS，禁止脚本、表单和远程资源。图片可使用内嵌 PNG/JPEG/WebP/GIF Data URI；CSS 不接受 url() 或 @import。

## 本地模型与许可证

背景移除按需下载固定版本的 BiRefNet_lite-ONNX，约 224 MB，可取消。模型缓存保存在浏览器，清理站点数据后需要重新下载；输入图片不会随模型请求上传。首次使用需要能访问 Hugging Face。

人脸检测使用随站点发布的 TinyFaceDetector 权重。检测后可手动补充或删除区域，再执行遮盖。设备和图片会影响检测效果。

组件和模型来源见站点 `image-models/sources.json`，许可证原文见仓库 `licenses/images/`。项目继续使用 GPL-3.0-only。实现验收记录见 [checklist spec](specs/IMAGE_TOOLS_CHECKLIST.md)。

本轮为独立图片工作区，尚未接入 SDK、MCP 或跨工具配方。
